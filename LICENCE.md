## 🧩 About

**Overwatch 2 Client** is a comprehensive client for Overwatch 2 featuring overlay, aim assist, ESP, hero scripts, streamproof, and config system.

Based on popular clients like **Visor**, **Kern**, and **Foxy**. 

---

## ✨ Features

### 🎯 Combat
- Aim Assist — smooth aimbot with customizable FOV and smoothing
- Silent Aim — hit targets without visible snap
- Triggerbot — automatic fire when crosshair is on target
- Prediction — account for projectile travel time and movement

### 👁️ Visuals
- ESP — player boxes, health bars, names, and distances
- Skeleton ESP — see player bones through walls
- Item ESP — highlight health packs and objectives
- Streamproof — hide overlay from recordings and streams

### 🛠️ Utility
- Hero Scripts — Lua scripting for custom hero logic
- Config System — save and load multiple profiles
- Menu Customization — change colors, keybinds, and layout
- Auto-Updater — stay current with game patches
